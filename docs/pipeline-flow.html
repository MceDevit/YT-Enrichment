Get the transcript
fetch_transcript() · yt-dlp

Three ways this can go, checked in order:

1 — a transcript is already in the note
Reused, fetch skippedlooks_raw() decides below whether it still needs cleaning
2 — otherwise, video exceeds max_transcript_minutes
Skipped on purposedeliberate, per your settings — stays reviewed, not flagged
3 — otherwise, fetched fresh via yt-dlp
Captions foundretried with backoff if rate-limited (429)
No captions existflagged — nothing to summarize
Clean the transcript
reformat_transcript() · claude_api.call_claude()

Runs on a fresh transcript, or on an existing one only if it still looks_raw() — timestamp markers, near-zero punctuation. A transcript someone already cleaned up by hand is left alone. Punctuation, paragraphs, stripped timestamps — retried on timeout/429/5xx with backoff.

Before the result is trusted
Right length, same languageused, model_reformat recorded
Truncated / translated / timed outdiscarded — raw captions kept, note flagged
Summarize against your topics
claude_summary() · _youtube_settings.md

Title/channel matched against your keyword topics for a per-subject focus, written in the video's own language, then judged plainly — the prompt is told to be critical, not polite.

Regular video4–6 bullets + one-line verdict
Short1–3 bullets, no verdict asked for
